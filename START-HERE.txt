제시간 · TIME QUEST — TMAP 전환본

1. ZIP 전체를 새 폴더에 압축 해제하세요.
2. 이전 서버 실행 창을 Ctrl+C로 종료하세요.
3. SET-TMAP-KEY.cmd를 더블클릭하고 SK TMAP appKey를 붙여넣은 뒤 Enter를 누르세요.
4. START-WINDOWS.cmd를 더블클릭하세요. Node.js 22 이상이 필요합니다.
5. Ready가 표시되면 http://localhost:3000 을 여세요.

이 버전은 ODsay 키를 사용하지 않습니다.
TMAP appKey는 아직 받지 않았으므로 설정 칸이 비어 있습니다.
SK open API에서 해당 앱에 '대중교통 API' 상품을 연결해야 합니다.
도보 전용 길찾기는 'TMAP 보행자 경로안내' 상품 권한도 필요합니다.
기존 카카오 지도·REST 키는 유지했습니다. 예제 파일로 설정을 덮어쓰지 마세요.

사용 흐름:
목적지 검색 및 주소 선택 → 마감시간 → 뛰기/택시 선택 → 길찾기 시작.
버스·지하철·환승 등 실제 조회된 수단이 경로 카드에 표시됩니다.
위치가 움직이면 지도 포인트와 남은 보행 안내가 갱신됩니다.
자동 경로 조회는 위치 변화를 묶어 최소 10초 간격으로 실행합니다.
실제 도착·승차·하차 뒤 확인 버튼을 누르세요.

TMAP 상세 경로 응답 자체에는 개별 차량의 실시간 도착분이 없습니다.
실시간 도착 탭은 별도 서울시 API 키를 넣었을 때 지원 범위에서 동작합니다.
TMAP 무료 대중교통 API는 하루 10건 한도이므로 반복 시험 전 상품 한도를 확인하세요.
오류가 계속되면 화면의 '오류 내용 복사' 내용을 전달해 주세요.

이 ZIP에는 개인 카카오 설정이 포함되어 있으므로 공개 저장소에 올리지 마세요.
세부 설정 및 확인 방법은 README.md에 있습니다.
